## Contenido

### Laboratorio 3: Estructuras de Datos

Este notebook cubre los siguientes temas:

- **Conversión de bases numéricas:** Función para convertir números decimales a binario
- **Números primos:** Función para determinar si un número es primo
- **Estadística básica:** Cálculo de desviación estándar sin funciones predefinidas
- **Algoritmos de ordenamiento:** Implementación del algoritmo de ordenamiento burbuja
- **Manipulación de tuplas:**
  - Conversión de tuplas a strings
  - Eliminación de tuplas vacías
  - Cálculo de promedios de tuplas anidadas
- **Programación orientada a objetos:**
  - Clase `Libro`: Representa un libro con título, autor, páginas y estado de lectura
  - Clase `Circulo`: Calcula área y circunferencia de un círculo

### Laboratorio 4: Análisis de Datos con Python

Este notebook cubre los siguientes temas:

- **NumPy:**
  - Creación y manipulación de arrays
  - Cálculo de tamaño en memoria
  - Slicing y selección de subarrays
  - Operaciones matemáticas con arrays
- **Pandas:**
  - Lectura y análisis de archivos CSV
  - Manipulación de DataFrames
  - Filtrado y selección de datos
  - Cálculos estadísticos (promedio, desviación estándar)
- **Matplotlib:**
  - Visualización de datos
  - Creación de gráficos

## Requisitos

Para ejecutar los notebooks, necesitas tener instalado:

- Python 3.x
- Jupyter Notebook o JupyterLab
- NumPy
- Pandas
- Matplotlib

## Instalación de dependencias

```bash
pip install numpy pandas matplotlib jupyter
```

## Uso

1. Clona el repositorio:
   ```bash
   git clone https://github.com/franciscogonzalez-gal/ciencia_datos_python.git
   ```

2. Navega al directorio del proyecto:
   ```bash
   cd ciencia_datos_python
   ```

3. Inicia Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

4. Abre cualquiera de los notebooks disponibles para explorar los ejercicios.
